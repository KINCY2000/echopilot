# EchoPilot MVP — interface de démonstration

Premier socle visuel du SaaS EchoPilot, réalisé avec Next.js, TypeScript, Tailwind CSS, Lucide et Recharts.

## Installation

1. Installez Node.js 20.9 ou une version plus récente.
2. Ouvrez un terminal dans ce dossier.
3. Lancez :

```bash
npm install
npm run dev
```

4. Ouvrez http://localhost:3000

## Ce qui fonctionne déjà

- Tableau de bord responsive
- Indicateurs de réputation
- Graphiques de démonstration
- Sélection d'un avis
- Analyse IA simulée
- Choix du ton
- Réponse générée simulée
- Bouton de publication simulé

## À connecter ensuite

- Supabase pour les comptes et les données
- Google Business Profile API pour les vrais avis
- OpenAI API pour les réponses réelles
- Stripe pour les abonnements
